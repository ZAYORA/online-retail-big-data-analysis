# 📊 Online Retail Big Data Analysis with PySpark

This project focuses on processing and analyzing the Online Retail dataset using PySpark.

The project was developed as part of a Big Data practical assignment to practice data processing, transformation, and analysis using Apache Spark.

## 🎯 Objectives

- Learn how to process data using PySpark.
- Work with Spark DataFrames.
- Perform data filtering and transformation.
- Perform grouping and aggregation.
- Apply sorting and repartitioning.
- Explore descriptive statistics.
- Practice basic data cleaning.
- Export processed data into CSV format.

## 📊 Dataset

The project uses the **Online Retail dataset** from the UCI Machine Learning Repository.

The dataset contains transaction records from a UK-based online retail business.

The dataset is used to practice Big Data processing and analysis with PySpark.

> The raw dataset is not included in this repository.

## 🛠️ Tools & Technologies

- Python
- PySpark
- Pandas
- Apache Spark
- Jupyter Notebook / Google Colab

## 🔍 Analysis Process

The notebook covers the following processes:

1. Creating a Spark Session
2. Loading the dataset
3. Exploring the data
4. Converting data into a PySpark DataFrame
5. Filtering data
6. Grouping and aggregating data
7. Sorting data
8. Repartitioning data
9. Performing descriptive statistical analysis
10. Cleaning the data
11. Exporting processed data into CSV format
